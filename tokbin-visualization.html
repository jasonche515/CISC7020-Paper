Rule cheat-sheet
TokBinR (root)
R_erRoot: neighbourhood not synced / not all reset / not all in error → br:=⊤
R_go: all neighbours cleaned up → br:=1

TokBinV (non-root)
R_er: b≠⊤ ∧ Er(v) → t:=wait, b:=⊤
R_reset: b=⊤ ∨ Er_var → rk:=⊥, t:=false, b:=0
R_erRank: ¬Er ∧ rk≠⊥ ∧ t=false ∧ TakeO → t:=wait, b:=⊤
R_join: ¬Er ∧ rk=⊥ ∧ TakeR → rk:=rkt, b:=1
R_tok: ¬Er ∧ rk≠⊥ ∧ t=false ∧ TakeP → t:=true
R_add: ¬Er ∧ t=true → t:=wait, b:=(b+1)%2
R_ready: ¬Er ∧ t=wait → t:=false
Three deliberate deviations from the paper (otherwise a random initial configuration livelocks forever):
(1) The enabling condition of R_go is relaxed from “all neighbours b=⊤” to “all ⊤ or all Reset”: a dormant node has no error left to receive and never becomes ⊤, so the root would park at ⊤ and stop emitting tokens forever.
(2) Er_pi compares only ranked neighbours. If ⊥ neighbours were included, phases inside a cleanup wave always disagree, so Er_pi self-triggers an unbounded R_er/R_reset oscillation.
(3) A node already in Reset(v) does not re-enter error merely because a neighbour holds ⊤, which avoids ⊤ ping-ponging between two adjacent nodes.
